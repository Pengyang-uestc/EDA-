## 四、各模块进展（每人汇报自己的一段）

### 成员A — 界面（src/ui/）
- 主窗口三栏布局：左侧元件库树、中间绘图区、右侧属性表，改属性即时生效。
- 完整菜单栏/工具栏/快捷键（F5 仿真、F6 视图、Ctrl+Z/Y 撤销重做、Delete 删除）。
- 自定义元件对话框：真值表定义新元件；未保存关闭有提醒。
- 关键决策：画布通过"提示回调"上报状态，不直接依赖主窗口（依赖倒置，方便测试）。

### 成员B — 交互（src/editor/，兼 core/）
- 全部画布交互：放置、拖动、框选、连线、删除、复制粘贴（含内部连线保留）、撤销重做。
- 连线校验：非法连线在状态栏提示；支持反向点选引脚；单线删除。
- 视图操作：滚轮缩放、中键平移、Ctrl+0 复位；双缓冲绘制防闪烁。
- **位号自动重排（Ctrl+R）**：按画布坐标从上到下、从左到右把元件连续重编号（U1、U2…），连线引用同步更新，支持撤销。
- 关键决策：快照式撤销（整个电路 JSON 压栈，不必为每个操作写逆操作）；网格吸附 10px。
- 直角自动布线：横竖折线并取半程通道，避免导线压在引脚上。

### 成员C — 文件（src/file/）
- `.eda` 工程格式（JSON），保存/打开/未保存提醒/文件异常保护（坏文件不破坏当前工程）。
- KiCad 网表导出（s-expression）与导入；KiCad 原理图导出，KiCad 10.0.6 实测可打开。
- 关键决策：网络归并用并查集——多元件连到同一导线时正确合并为一个网络，解决扇出错误。
- 子电路 `.edasub` 格式：把完整电路封装为多输入多输出元件，跨工程复用。
- **子电路元件管理**：对话框集中查看/删除已定义的子电路元件，删除支持撤销重做。

### 成员D — 仿真与测试（src/sim/ + test/）
- 仿真引擎：从开关出发迭代传播逻辑值至稳定；导线按 0/1 着色，灯显示结果。
- 时序仿真：顶层 D 触发器（上升沿采样）+ 时钟源，500ms 自动步进。
- 子电路合并兼容测试 53 项：保证封装/展开/再保存数据不丢。
- 测试体系：单元测试（185 项实测 PASS）→ GUI 自动化交互 → 半加器四种输入组合端到端验收。

## 六、开发过程与遇到的困难

- 按目录分工，每人独立地盘；core/ 全组共用，改动先沟通。全程 Git 主线开发，54 次提交，期间完成一次大规模目录重构与子电路功能合并（PR 协作）。
- 主要困难及解决：
  - 中文/编码问题（UTF-8 vs GBK）→ 编译统一 `/utf-8`；
  - 或门弧线方向错 → 折线近似；
  - 删除"静默失败"难察觉 → 状态栏提示回调；
  - 网表扇出连接错误 → 并查集归并；
  - 多人并行开发冲突 → 目录级分工 + 小步提交 + rebase 合并。

## 七、现场演示流程（5 分钟）

准备：运行 `MyEDA\build\Debug\MyEDA.exe`（演示包与源码同版本，避免现场联网更新；编辑用副本，保留原始样例）。

1. **界面（成员A）**：介绍三栏布局；点菜单、按 F5/F6/Ctrl+Z 演示快捷键。
2. **画电路（成员B）**：拖一个开关和一个灯，连线（演示多拐点、反向点选也能连）；故意错误连线看状态栏提示；滚轮缩放、Ctrl+0 复位；框选复制粘贴；按 Ctrl+R 演示位号自动重排。
3. **仿真（成员D）**：打开 `examples/half_adder/half_adder.eda`，按 F5，依次切换输入 00/01/10/11——和输出 0/1/1/0、进位 0/0/0/1；演示时序步进。
4. **文件（成员C）**：另存 `.eda`；导出 KiCad 网表展示 nets 段；（提前备好截图）KiCad 打开我们导出的原理图/网表。
5. **加分项**：打开 `examples/subcircuits/` 演示子电路封装；工程→管理子电路元件，展示查看/删除与撤销。

兜底：半加器样例提前开好放后台，现场画电路出问题直接切样例。完整演练清单见[阶段展示检查清单](阶段展示检查清单.md)。
