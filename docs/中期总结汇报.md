## 四、各模块进展（每人汇报自己的一段）

### 成员A — 界面（src/ui/）
- 主窗口三栏布局：左侧元件库树、中间绘图区、右侧属性表，改动属性即时生效。
- 完整菜单栏/工具栏/快捷键（F5 仿真、Ctrl+Z/Y 撤销重做、Delete 删除）。
- 自定义元件对话框：用真值表定义新元件；关闭未保存工程时弹窗提醒。
- 关键决策：画布通过"提示回调"上报状态，不直接依赖主窗口（依赖倒置，方便测试）。

### 成员B — 交互（src/editor/，兼 core/）
- 全部画布交互：放置、拖动、框选、连线、删除、复制粘贴、撤销重做。
- 双缓冲绘制防闪烁；命中测试支持元件/引脚/导线。
- 关键决策：快照式撤销（整个电路 JSON 压栈，不用为每个操作写逆操作）；网格吸附 10px 保证连线整齐。
- 直角自动布线：连线自动走横竖折线并取半程通道，避免导线压在引脚上。

### 成员C — 文件（src/file/）
- `.eda` 工程格式（JSON），保存/打开/未保存提醒。
- KiCad 网表导出（s-expression 格式）与导入；KiCad 原理图导出。
- 关键决策：网络归并用并查集——多个元件连到同一根导线时正确合并为一个网络，解决扇出错误。

### 成员D — 仿真与测试（src/sim/ + test/）
- 仿真引擎：从开关出发迭代传播逻辑值，直到稳定；导线按 0/1 着色，灯显示结果。
- 时序仿真：D 触发器、时钟源、单步运行模式。
- 67 项单元测试覆盖逻辑/存档/网表/交互四类；半加器真值表作为端到端验收。

## 六、开发过程

- 按目录分工，每人有独立地盘；core/ 全组共用，改动先沟通。
- 全程 Git 管理主线，47 次提交可追溯；文档与代码同步更新。
- 遇到的主要困难及解决：
  - 中文/编码问题（UTF-8 vs GBK）→ 编译加 `/utf-8` 统一源码字符集；
  - 或门弧线绘制方向错 → 改用折线近似；
  - 删除操作"静默失败"难以察觉 → 加状态栏提示回调；
  - 网表扇出连接错误 → 并查集归并网络。

## 七、现场演示流程（5 分钟，照做即可）

准备：双击 `update-and-run.bat`（或直接运行 `MyEDA\build\Debug\MyEDA.exe`）。

1. **界面（成员A）**：介绍三栏布局；点几个菜单、按 F5/Ctrl+Z 演示快捷键。
2. **画电路（成员B）**：从元件库拖一个与门和一个开关，连线，框选拖动，Ctrl+Z 撤销。
3. **仿真（成员D）**：文件→打开 `docs/样例/半加器/half_adder.eda`，按 F5，点击开关，看导线变色、灯亮灭；切换单步模式演示时序。
4. **文件（成员C）**：另存 `.eda`；导出 KiCad 网表；展示网表文本中的 nets 段。
5. **互操作**：（提前录屏/截图）KiCad 打开我们导出的原理图/网表。

演示保险：提前打开半加器样例放在后台，若现场画电路出问题直接切样例。

## 八、存在问题与下一步计划

存在问题：
- 时序仿真没有波形动画，只能单步观察；
- 元件固定双输入，不支持 3+ 输入门；
- 无打印/PDF 导出；
- KiCad 样例只完成网表/原理图对接，未做 PCB 布线。

下一步计划（中期→结题）：
1. 补充波形/动画展示，让仿真过程更直观；
2. 元件引脚数泛化（支持 3+ 输入）；
3. 完善课程报告（按 docs/课程报告写作指南.md 组织）；
4. 按最终答辩 PPT 大纲（docs/答辩PPT大纲与分工表.md）排练结题汇报。
