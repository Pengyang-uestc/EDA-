## 一、老师任务 5 定标解读（最重要）

老师定标的开源工具链是 **gEDA：gschem（原理图）+ gsch2pcb（网表）+ pcb（PCB）**，
不是 KiCad。PDF 结论（第 8 页）：

> 自开发的原理图需要输出如下标准文件给 pcb：
> 1）初始 pcb 文件 full_adder.pcb
> 2）网表文件 full_adder.net

老师给的样例就是**一位全加器**（和我们 examples/subcircuits 里的全加器正好对应），
完整走完：画原理图 → 分配 RefDes+Footprint → gsch2pcb 生成 .net+.pcb → pcb 加载 →
飞线 → 自动布线 → 导出 BOM/坐标/Gerber（样例文件/ 目录 13 个文件就是最终产出）。

### 格式要点（照老师样例逆向）

`.net`（纯文本，每网一行，TAB 分隔）：
```
unnamed_net6	U1-3 U1-4 U2-5
Vcc	U3-14 U1-14 U2-14
```

`.pcb`（gEDA pcb 文本格式）：文件头（FileVersion/PCB/Grid/DRC/Styles）+
每个元件一个 `Element(0x00 "DIP14" "U3" ...)` 块内含 14 个 `Pin(...)`。

### 对策（第一版做减法）

- `.net` 导出：基于现有电气网表模型（Netlist.h），每个网络一行 `名称<TAB>位号-引脚`，约 1 天。
- `.pcb` 导出：固定 DIP14 模板 + 按位号网格排布，约 2~3 天。
- **多门 IC 的 slot 概念第一版规避**：每个逻辑门用单门芯片（74AHC1G08/32/86，
  老师 PDF 明确列了这组 KiCad 标准件，物理上成立），不必实现"同片多门共用 RefDes+slot"。
- 验证闭环：WSL Ubuntu 安装 gEDA pcb → File→Load layout + Load netlist →
  按 O 飞线 → Connects→Auto-route all rats → Export gerber/bom，全程截图。
