# 新人上手指南(怎么把项目跑起来)

> 给第一次拿到这个项目的组员。**全程不用敲编译命令,双击一个文件就行。**
> 遇到任何报错,截图发群里,不要自己乱试。

---

## 一、先确认电脑上装好了三样东西

| 需要 | 怎么确认 |
|---|---|
| Visual Studio 2022(或 BuildTools,含 C++ 工具) | 开始菜单能搜到 "Visual Studio Installer" |
| CMake | 打开一个终端输入 `cmake --version`,能看到版本号 |
| wxWidgets 3.2.2.1(源码 + 已编译好的库) | 有一个 `wxWidgets-3.2.2.1` 文件夹,里面 `lib\vc_x64_lib\` 下有 `.lib` 文件 |

> 这三样按课程《基础工具软件搭建指南》装。**没装好之前,下面的步骤会失败。**

---

## 二、把项目弄到电脑上

### 情况 A:第一次拿项目(电脑上还没有)

1. 在你想放项目的位置(比如 `D:\`)新建一个文件夹,进去
2. 在文件夹空白处**右键 → Open Git Bash here**(或"在终端中打开")
3. 输入下面这行回车(国内直连 GitHub 慢,用镜像地址):

```bash
git clone https://ghfast.top/https://github.com/Pengyang-uestc/EDA-.git
```

4. 完成后会多出一个 `EDA-` 文件夹,里面是项目

### 情况 B:之前已经克隆过(想把最新代码同步下来)

1. 进入项目文件夹(有 `README.md`、`build.bat` 的那个)
2. 右键 → Open Git Bash here → 输入:

```bash
git pull
```

> `git pull` 的意思是:"把 GitHub 上别人新提交的代码拉下来,和我本地的合并"。
> 这就是"同步最新版本"。

---

## 三、编译(双击就行)

进入项目文件夹,**双击 `build.bat`**。

它会自动做四件事,你只需要等:

```
√ 找到 wxWidgets: D:\...\wxWidgets-3.2.2.1
[1/3] 生成 Visual Studio 工程 ...
[2/3] 编译程序 ...
[3/3] 跑单元测试(期望看到 ALL PASS) ...
=== ALL PASS ===

全部完成!程序在这里:
  D:\...\EDA-...\MyEDA\build\Debug\MyEDA.exe
  双击运行即可;也可以带一个电路文件打开:
  MyEDA.exe docs\样例\半加器\half_adder.eda
```

**看到 "全部完成" 四个字 = 成功。** 第一次编译大约 1~2 分钟。

---

## 四、运行程序

直接双击 `MyEDA\build\Debug\MyEDA.exe`。

想直接打开现成的电路,用命令行带路径(或者把 `.eda` 文件拖到 exe 上):

```bash
MyEDA\build\Debug\MyEDA.exe docs\样例\半加器\half_adder.eda
```

---

## 五、改了代码之后怎么办

**再双击一次 `build.bat`** 就行。不用删任何目录,CMake 会自动重新生成工程。

---

## 六、常见问题

| 现象 | 原因 / 怎么办 |
|---|---|
| 提示"找不到 wxWidgets" | 脚本没在默认位置找到它。把 wxWidgets 文件夹的实际路径发群里;或者自己在 PowerShell 里执行:<br>`.\build.ps1 -Wx "D:\你的路径\wxWidgets-3.2.2.1"` |
| `git clone` / `git pull` 卡住或报连不上 | 网络问题。用上面的镜像地址;有梯子的话也可以用 `https://github.com/Pengyang-uestc/EDA-.git` |
| 编译报一堆红色 error | 先试 `.\build.ps1 -Clean`(会删掉 build 重新来);还不行就把**最前面几条报错**截图发群里 |
| 双击 `build.bat` 窗口一闪就没了 | 在文件夹里右键 → Open Git Bash here,输入 `./build.bat` 运行,这样能看到报错 |
| 想知道"我该看哪部分代码" | 看 `docs/分工与答辩手册.md`,里面按人分了模块 |
