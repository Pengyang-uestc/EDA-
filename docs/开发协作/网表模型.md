# 电气网表模型

`MyEDA/src/core/Netlist.h` 独立于 KiCad 文本格式，提供 BuildNets 与 BuildCircuitNetlist。

每个 ElectricalNet 有编号、全部引脚、驱动引脚和接收引脚。CircuitNetlist 还列出未连接引脚、错误和警告。网络由导线端点归并，交叉的几何线条不会自动成为连接点。

错误包括元件 ID 无效或重复、端点不存在、引脚越界、同一网络多驱动。KiCad 导出遇到这些错误返回失败。没有驱动的网络作为警告保留，允许检查参考网表；编辑器导入逻辑工程仍有更严格的校验。孤立引脚单独列出，不虚构为已连接的网络。

子电路在 KiCad 导出前展开，并对展开后的电气网络检查。当前仿真仍通过原有逐引脚输入读取接口求值，未改成以 CircuitNetlist 为唯一求值入口。网络标签、总线、几何交点自动连接以及诊断面板尚不在本次改动中。

发布版回归：test_sim 69 项、test_modules 53 项、test_canvas 59 项，共 181 项。安装使用根 README 的 CMake 流程，无需 BAT 快捷启动脚本。
